Machine Learning Project

Telecom Churn Decision Framework

A decision-oriented telecom churn prediction framework using class-imbalance handling, threshold optimization, and explainable AI.

5 × 4 Models × Imbalance Strategies
5-Fold Stratified Cross-Validation
53.2% → 86.1% Recall Improvement
175 → 52 False Negatives Reduced

Project Highlights

  • Evaluated 5 ML models × 4 imbalance strategies with stratified 5-fold cross-validation and Average Precision.
  • Built a leakage-safe pipeline with hyperparameter tuning, OOF prediction, threshold analysis, and FN/FP decision-cost evaluation.
  • Selected XGBoost with a 0.18 decision threshold, improving recall from 53.2% to 86.1%.
  • Reduced false negatives from 175 to 52.
